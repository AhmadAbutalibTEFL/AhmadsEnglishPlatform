# Image assets

## Portrait (About Me section)

Add your own photo here as:

    assets/images/ahmad-portrait.jpg

- Format: JPG (or re-save as `.jpg`); colour is fine, because the site converts it to black and white with CSS.
- Shape: portrait orientation, about 4:5 (for example 800 x 1000 px). The page crops to this shape and keeps the top of the image (head and shoulders work best).
- Size: aim for under 300 KB.
- Use only a photo you own or have permission to publish, and update `ASSET_CREDITS.md` if anyone else took it.

Until the file exists, the About section shows a neutral "AA" placeholder and the browser console shows one harmless 404 for this path.
